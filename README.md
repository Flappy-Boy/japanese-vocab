# 日语单词背诵 · 新标准日语教程 第一册

一个用来背单词的单页网站，词库来自《新标准日语教程 第一册（智慧版）》第 1–12 課的「単語」框，逐页整理。

**共 901 个词**，保留教材原样的音调符号（⓪①②③）与词性缩写（名／他五／自五／形1／形2／副／助 …）。

## 功能

### 闪卡背诵
正面显示单词（可开关假名），点击卡片或按 `空格` 翻面查看读音、音调、词性、中文释义，再用 `1` `2` `3` 评分：

| 按键 | 按钮 | 效果 |
| --- | --- | --- |
| `1` | 不认识 | 打回「学习中」 |
| `2` | 模糊 | 升到「熟悉」 |
| `3` | 认识 | 升到「已掌握」 |

### 测验
四种题型：日语 → 中文意思、中文 → 日语、日语 → 假名读音、混合。
四选一，答错立刻标红并给出正确答案，带正确率与连对计数。
支持 `1`–`4` 选项、`Enter` 下一题、「答对自动下一题」。

### 变形练习（动词活用）
用课本里出现的 **75 个真实动词**练**六种形态**。四个选项是**同一个动词的错误变形**（比如「読みて」「読た」「読いて」），逼你真的判断活用规则，而不是靠认词。

可选题型：**て形 / た形 / ます形 / 第一连用形 / 未然形 / ない形 / 混合**。

答完立刻给出：
- 正确形式（含假名）
- **活用规则**（例如「む → んで（拨音便）」「五段动词：词尾「む」→ ア段「ま」＋ない」）
- **完整链条**：未然形 → 第一连用形 → ます形 → て形 → た形 → ない形

还带一张**全部动词变形表**（可折叠），按课列出每个动词的六个形态与活用规则。

#### 课本第一册的完整活用体系

以五段动词「読む」为例：

| 形态 | 形式 | 用途 / 接续 |
| --- | --- | --- |
| 未然形 | 読**ま** | ＋ない（否定） |
| 第一连用形 | 読**み** | ＋ます（敬体） |
| 第二连用形 | 読**ん** | ＋て／た |
| て形 | 読**んで** | 中顿、正在、请…… |
| た形 | 読**んだ** | 过去、完成、あとで |
| ない形 | 読**まない** | 否定 |

#### 各类动词的规则

| 类型 | 未然形（＋ない） | 第一连用形（＋ます） | 第二连用形（＋て／た） |
| --- | --- | --- | --- |
| 五段 う | わ | い | って／った（促音便） |
| 五段 つ・る | た・ら | ち・り | って／った（促音便） |
| 五段 む・ぶ・ぬ | ま・ば・な | み・び・に | んで／んだ（拨音便） |
| 五段 く・ぐ | か・が | き・ぎ | いて／いた、いで／いだ（イ音便） |
| 五段 す | さ | し | して／した |
| 一段 | 去る | 去る | 去る＋て／た |
| サ変 | し（另有 せ・さ） | し | して／した |
| カ変 | 来（こ） | 来（き） | 来て／来た |
| 例外 | — | — | 行く → いって／いった |

> 注意：**一段动词的未然形与第一连用形同形**（都是去掉「る」）；**サ変的未然形有三个**（し・せ・さ），接「ない」时用「し」，所以练习里不会把「せ」「さ」当作错误选项。

## 其他

- **按课筛选**：第1課 発音 34 词 … 第12課 現代社会 86 词；也可选「全部 12 課」或「★ 只看没掌握的」。

- **URL 参数**：`?tab=quiz&lesson=7` 直接进入第 7 课的测验；`?tab=drill` 进变形练习；`?tab=drill&ref=1` 直接展开变形表；`?tab=list` 进词表。

## 词库整理说明

- 教材在多个「単語」框中重复印过的词**已合并**，每课只列一次（例如第 8 課教材印 100 个，去重后 98 个）。
- **第 4 課的 58 个辨音练习词**（`じゅう`／`びょういん` 这类长音、促音最小对立对，教材未给释义）**未收入词库**——没有释义的词无法用于闪卡。若需练习听辨，可另行整理。
- 第 12 課整理时发现的 4 处「印刷不清、按教材常见标注推定」的词（如 `何故` → `なぜ`），保留按通行读音抄录的版本。

## 本地使用

这是**单文件、零依赖**的静态站点，所有词库与逻辑都内嵌在 `index.html` 中，不联网也能用。直接双击 `index.html` 即可，或起个本地服务：

```bash
python -m http.server 8848
```
