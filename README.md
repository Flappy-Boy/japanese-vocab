# 日语单词背诵 · 新标准日语教程 第一册

一个用来背单词的单页网站，词库来自《新标准日语教程 第一册（智慧版）》第 1–12 課的「単語」框，逐页整理。

**共 901 个词**，保留教材原样的音调符号（⓪①②③）与词性缩写（名／他五／自五／形1／形2／副／助 …）。

## 在线使用

https://flappy-boy.github.io/japanese-vocab/

## 功能

### 闪卡背诵
正面显示单词（可开关假名），点击卡片或按 `空格` 翻面查看读音、音调、词性、中文释义，再用 `1` `2` `3` 评分：

| 按键 | 按钮 | 效果 |
| --- | --- | --- |
| `1` | 不认识 | 打回「学习中」 |
| `2` | 模糊 | 升到「熟悉」 |
| `3` | 认识 | 升到「已掌握」 |

### 测验
四种题型：日语 → 中文意思、中文 → 日语、日语 → 假名读音、混合。
四选一，答错立刻标红并给出正确答案，带正确率与连对计数。
支持 `1`–`4` 选项、`Enter` 下一题、「答对自动下一题」。

### 词表总览
全部 901 词按课分组，可按关键词搜索（单词／假名／中文／词性）、按课筛选、按掌握状态筛选。
每行右侧 🔊 发音，点状态按钮可直接改熟练度。

## 其他

- **按课筛选**：第1課 発音 34 词 … 第12課 現代社会 86 词；也可选「全部 12 課」或「★ 只看没掌握的」。
- **发音**：使用浏览器内置的日语语音合成（`ja-JP`）。系统若未安装日语语音包，🔊 将无声。
- **进度保存**：学习进度存在浏览器 `localStorage` 里，换浏览器或清缓存会丢失。
- **URL 参数**：`?tab=quiz&lesson=7` 可直接进入第 7 课的测验；`?tab=list` 进入词表。

## 词库整理说明

- 教材在多个「単語」框中重复印过的词**已合并**，每课只列一次（例如第 8 課教材印 100 个，去重后 98 个）。
- **第 4 課的 58 个辨音练习词**（`じゅう`／`びょういん` 这类长音、促音最小对立对，教材未给释义）**未收入词库**——没有释义的词无法用于闪卡。若需练习听辨，可另行整理。
- 第 12 課整理时发现的 4 处「印刷不清、按教材常见标注推定」的词（如 `何故` → `なぜ`），保留按通行读音抄录的版本。

## 本地使用

这是**单文件、零依赖**的静态站点，所有词库与逻辑都内嵌在 `index.html` 中，不联网也能用。直接双击 `index.html` 即可，或起个本地服务：

```bash
python -m http.server 8848
```
